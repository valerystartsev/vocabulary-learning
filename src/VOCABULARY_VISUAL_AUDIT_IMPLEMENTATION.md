## VISUAL SYSTEM PROPERTIES

### Design Language
- **Minimalist 2D**: All icons are clean vector symbols
- **Lucide-React Compliance**: Every icon exists in lucide-react library
- **Course Alignment**: Icons match "Three Key Ideas" educational aesthetic
- **Semantic Integrity**: Each icon embodies the word's core meaning
- **Memory Support**: Icons aid recall through visual metaphor

### Differentiation Strategy
**Money Terms:**
- `revenue`: $ upward = inflow
- `refund`: ← = reverse flow
- `rental`: home = space rental
- `bill`: document = invoice obligation
- `returns`: ↑ = profit return
- `save`: piggy bank = storing

**Power/Authority Terms:**
- `authority`: shield = official power
- `authorize`: checkmark = permission granted
- `permit`: zap = permission to activate
- `control`: sliders = managing forces
- `restrict`: barrier = limiting access

**Employment Terms:**
- `hire`: briefcase = job employment
- `redundant`: X = eliminated position
- `retrain`: brain = new learning path
- `recruit`: plus = adding member
